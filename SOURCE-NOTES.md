# Source Notes

This documentation package was prepared from the supplied `admin_v62(1).html` source.

The source identifies the application as a Raja Electronics Admin Console and documents:
- client-side authentication limitations;
- the `Auth` seam;
- the `Repo` repository layer;
- same-origin browser-storage integration;
- admin-side product/cancelled-order/review-moderation integration limitations;
- audit logging;
- notifications;
- workbook exports;
- accessibility and appearance settings.

These notes are intentionally separated so the GitHub documentation can distinguish current source behavior from recommended production architecture.
